## Рубрика приёмки

- [ ] Server реализует границу и первую capability из 6.2, а не новый несвязанный demo.
- [ ] Primitive выбран по владельцу инициативы и форме результата.
- [ ] Имя, описание, type hints и output type задают понятный публичный контракт.
- [ ] Listing подтверждает ожидаемый descriptor и schema.
- [ ] Успешный вызов возвращает проверенный предметный результат.
- [ ] Некорректный вход или предметный miss наблюдаемы как ошибка, а не как успешный текст.
- [ ] Хотя бы одна проверка доказывает, что schema-invalid input не дошёл до domain handler.
- [ ] Сервер и тесты запускаются из чистого окружения по записанным командам.
- [ ] В проекте нет секретов и реальных чувствительных данных.
- [ ] Отдельно названы гарантии in-memory теста и проверки, оставленные 6.4–6.5.
