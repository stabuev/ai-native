## Рубрика приёмки

- [ ] Проверяется личный server из 6.3, а не новый несвязанный demo.
- [ ] Записаны версии, target и точные команды воспроизведения.
- [ ] Transport выбран по сценарию, а не ради демонстрации двух вариантов.
- [ ] Inspector evidence охватывает descriptor, success и ожидаемый failure.
- [ ] Host действительно выполнил ту же capability, а не только показал её название.
- [ ] В controlled failure изменена одна переменная и назван один подтверждённый слой.
- [ ] После исправления восстановлен исходный успешный вызов.
- [ ] Выводы не объявляют Inspector гарантией domain correctness или security.
- [ ] Config и logs обезличены; secrets в артефакте отсутствуют.
- [ ] В 6.5 передана конкретная открытая поверхность, а не абстрактное «добавить безопасность».
