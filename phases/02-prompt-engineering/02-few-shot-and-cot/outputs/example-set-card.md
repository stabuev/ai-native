# Артефакт: карточка набора примеров

Карточка помогает решить, нужны ли промпту примеры, собрать только полезные пары
«вход → выход» и проверить их на новых случаях. Это рабочий документ, а не анкета:
оставляй только применимые строки, но не смешивай примеры в промпте с отложенной
проверкой.

> …

**Как выглядит пригодный результат?**

> …

```text
…
```

**Какой наблюдаемый дефект остался у версии без примеров?**

> …

**Можно ли исправить его одной ясной инструкцией?**

> …

Если конкретного дефекта или ожидаемого изменения нет, остановись: примеры пока не
обоснованы.

## 3. Кандидаты в набор

Колонка «что показывает» остаётся в карточке для автора и проверяющего. В сам промпт
обычно переносятся только согласованные вход и выход.

| ID | Вход | Желаемый выход | Что показывает | Оставить / изменить / удалить и почему |
|---|---|---|---|---|
| E1 | … | … | Типичный случай / формат / другое | … |
| E2 | … | … | Граничный случай | … |
| E3 | … | … | Контраст к E2 | … |

Проверка каждого кандидата:

- желаемый выход однозначно следует из входа и правил;
- пример похож на будущую рабочую нагрузку;
- он показывает новое различие, а не повторяет соседний;
- его формат согласован с инструкцией и другими примерами;
- в нём нет лишних персональных или конфиденциальных данных.

## 5. Итоговый блок примеров

Скопируй сюда только примеры, прошедшие проверку. Используй одинаковые разделители и не
добавляй служебные комментарии, если модель не должна возвращать их в ответе.

```text
Пример 1
Вход: …
Выход: …

Пример 2
Вход: …
Выход: …
```
