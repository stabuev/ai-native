# Артефакт: карточка внешней цепочки промптов

Карточка помогает решить, нужна ли рабочей задаче внешняя цепочка, и передать её другому
человеку без устных пояснений. Это не обязательная анкета для каждого запроса: если
контроль не окупает дополнительные шаги, зафиксируй решение оставить один промпт.

Удаляй лишние строки. У шага должен быть самостоятельный проверяемый выход; «прочитать»
и «подумать» сами по себе не являются полезными этапами цепочки.

## 5. Неизменяемый контекст

Что нельзя потерять при передаче между шагами:

- исходный источник: …
- цель пользователя и аудитория: …
- определения и ограничения: …
- критерии успеха: …
- сведения, которые запрещено додумывать или изменять: …

Выход предыдущего шага не заменяет этот контекст автоматически.
