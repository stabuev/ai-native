## 8. Решение о завершении

Фаза завершена, только если все утверждения ниже подтверждены ссылкой или наблюдаемым
результатом.

- [ ] Один собственный процесс проходит через артефакты 4.1–4.5.
- [ ] Каждый memory-кандидат трассируется до snapshot по `owner + key + record_id`.
- [ ] Preflight выполнен на собственных данных и его статус объяснён.
- [ ] P-01–P-06 выполнены, а найденные дефекты исправлены и перепроверены.
- [ ] Разрешения, внешние пути, ограничения и откат зафиксированы.
- [ ] Другой человек может повторить проверку по этому досье.
